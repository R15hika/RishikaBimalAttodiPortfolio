Project Overview ♡

  • A 3D training simulator for trainee AV shuttle fleet managers: spot a disruption, plan a detour, approve it with a reason, watch it run in 3D, then debrief.
  • Runs on real Toa Payoh roads with an OpenStreetMap basemap, real bus stops and textured 3D buildings.
  • Tabs for Fleet, Route planning, Charging, Incidents and Reports; the Unity client talks to a FastAPI backend that runs the simulation.

My Contribution ♡

  • Migrated the app from Qt to Unity and built the UI layout in UI Toolkit: login, fleet overview, incidents, charging, plus the real LTA/OpenStreetMap fleet map.
  • Set up login and accounts with MongoDB: sign-up and log-in against the team's shared account database.
  • Extruded Toa Payoh's real building footprints (OpenStreetMap) into 3D buildings, generating the meshes in Unity with custom shaders.
  • Built interactive battery scheduling end to end, from the data contracts and backend booking services to the Unity UI: charger bookings, return to route and charger markers, with tests.
  • Imported LTA traffic-light, crossing and road-marking data and served it through new API endpoints; gave each shuttle its own route and coloured stops.

Experience Gained ♡

  • Porting a working app to a new engine while keeping every workflow behaving the same.
  • Turning real open map data into 3D geometry, and being upfront about which parts are real and which are simulated.
  • Building features across the full stack: schemas, backend services, client UI and tests.
  • Working in a team repo with branches, pull requests and code reviews.
